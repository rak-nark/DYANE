### Playground

The Dynatrace Playground is a public sandbox environment provided by Dynatrace. It allows users to explore and interact with sample data without needing to install any software. This environment is designed to help users get familiar with Dynatrace’s features and capabilities, such as application observability, infrastructure analysis, and security diagnostics. In the Playground, you can: 
- **Explore various use cases**
  From monitoring Kubernetes clusters to analyzing synthetic tests.
- **Interact with live dashboards and notebooks**
  These provide hands-on tutorials and step-by-step instructions for different scenarios.
- **Test new features**
  Dynatrace regularly updates the Playground with new UI elements and functionalities.

You can find the Dynatrace Playground in the environment switcher in your account, or if you do not yet have a Dynatrace account, [sign up for Playground](https://www.dynatrace.com/signup/playground/).
